# Competitive Programming — Unipi

This repository contains the exercises, solutions, and reports for the competitive programming course.

## Folder guide

- `cpp/` — C++ solutions for the assigned problems.
- `src/` — Rust solutions, organized by problem name or problem number.
- `data/` — input and output files used to test the exercises.
- `helpers/` — shell scripts used to run and check the solutions.
- `reports/` — the written reports for each hands-on assignment.
- `target/` and `cpp/bin/` — compiled binaries and build artifacts.

## Where to find the solutions

The solutions are inside the `cpp/` and `src/` folders, depending on the language used for each exercise (All C++ solutions are duplicated in the `src/` folder under Rust implementation). Each file is named after the problem, so it is easy to match the code with the corresponding assignment.

## Where to find the reports

The reports are in the `reports/` folder, split by hands-on assignment:

- `reports/hands_on1/`
- `reports/hands_on2/`
- `reports/hands_on3/`

Each report folder contains the `.tex` file and its assets.

## Notes

The `data/` folder is useful for checking solutions locally with the provided test cases, and the scripts in `helpers/` can be used to automate those checks.
